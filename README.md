# Excel Portfolio Dashboard

An Excel-based portfolio analysis dashboard built to analyze a software/project portfolio across **15 projects from 2023–2025**.

The workbook demonstrates practical Excel data analysis, PivotTables, KPI reporting, dashboard design, and business insight generation.

## Key Insights

- **80% of projects are completed**, while 20% are still in progress.
- **Backend** is the most common skill category, appearing in 5 projects.
- **Frontend** and **Full Stack** each appear in 3 projects.
- **Data Analysis** appears in 2 projects.
- Projects were distributed across the three-year period: **4 in 2023, 6 in 2024, and 5 in 2025**.
- Project durations range from **3 to 12 weeks**.

## Workbook Structure

### `Portfolio Data`
Contains the project-level source data, including:

- Project Name
- Technology Used
- Skill Category
- Completion Status
- Experience Level
- Duration (Weeks)
- Year

### `Skill Analysis`
Analyzes the most common skill categories and technology usage.

### `Project Analysis`
Summarizes project completion status and project count by year.

### `Dashboard Summary`
Provides KPI cards and visual summaries for:

- Total projects
- Completed projects
- Projects in progress
- Most common skills
- Completion rate

### `Summary Insights`
Converts the analysis into concise business/project insights.

## Business Takeaways

The analysis shows a strong concentration in **Backend development**, while the portfolio also demonstrates exposure to Frontend, Full Stack, Data Analysis, AI/ML, and Mobile development.

The **80% completion rate** indicates that most projects in the portfolio have been completed, while the remaining projects are clearly identified as in progress.

The year-wise distribution also shows that project activity increased from 2023 to 2024 before remaining strong in 2025.

## Purpose

This project was created as a practical portfolio piece to demonstrate how Excel can be used to transform structured project data into an interactive, management-friendly analysis and dashboard.
